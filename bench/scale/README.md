# Большие программы

Замер проверки на больших программах (docs/lsp.md, шаг 3): сколько времени и памяти уходит на
проверку редактора (`tz lsp --check`), на `tz map` и сколько весят записи модулей.

```
python bench/scale/gen.py <каталог> <строк>
powershell -ExecutionPolicy Bypass -File bench\scale\measure.ps1 <каталог> 100000,1000000
```

`gen.py` пишет программу из модулей по ~500 строк: тип записи, тип ошибки, класс с методами,
функции с циклами, ошибками-`Result` и вызовами в модули, которые модуль импортирует (модуль `i`
импортирует `2i+1`, `2i+2` и `2i+3`, поэтому всё достижимо из `main.tz`, а граф неглубокий, как
в настоящем коде). `measure.ps1` делает по проекту на размер (`p<строк>`, один раз) и печатает
строку на размер: время и пиковую память проверки и `tz map`, размер записей (`tz query records`).
